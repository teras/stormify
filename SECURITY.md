# Security Policy

## Supported Versions

The latest 2.x release receives security updates.

## Reporting a Vulnerability

Please **do not open a public GitHub issue** for security vulnerabilities.

Report privately via GitHub Security Advisories:
https://github.com/teras/stormify/security/advisories/new

You can expect an initial response within 7 days. Once a fix is
available, disclosure will be coordinated with the reporter before the
advisory is published.
